## Data flow

### HTTP/1.x plaintext forward

```
Client ── GET http://host/path HTTP/1.1 ──→ http::serve
  → serve_connection (http1 with_upgrades)
    → outer_handler → forward_plaintext
      → relay:
        1. absolute_uri (origin-form → absolute)
        2. buffer body (Incoming → Bytes)
        3. inspect_request (Continue / Respond)
        4. snapshot_request_head
        5. strip_hop_by_hop
        6. ensure_host_header (Host for h1)
        7. upstream.send(false, host, 80, req)
        8. inspect_response
        9. into_full (remove TE/CL, wrap in Full)
```

### HTTP/1.1 CONNECT → MITM tunnel

```
Client ── CONNECT host:443 HTTP/1.1 ──→ http::serve
  → outer_handler
    → 200 response (immediate, body empty)
    → hyper::upgrade::on(req)
      → mitm_tunnel(upgraded, authority, peer, state)
        → TlsAcceptor::accept → TLS handshake (per-host cert)
        → ALPN: h2 → Protocol::Http2, else Http1
        → auto::Builder.serve_connection (h2 or http/1.1)
          → relay (same pipeline as above, secure=true)
```

### HTTP/3 (QUIC)

```
Client ── QUIC + h3 ──→ http3::serve
  → quinn endpoint accept → serve_connection
    → h3::server::builder().send_grease(false).build(...)
    → loop: h3_conn.accept() → resolve_request()
      → handle_request(req, stream, peer, state):
        1. drain body (recv_data loop)
        2. inspect_request
        3. ensure_host_header (h3 → skip)
        4. upstream.send(true, host, port, req)  // always HTTPS
        5. inspect_response
        6. send_response (head → data → finish)
```

## HTTP/3 stream-FIN bug — reference

**Symptom (aioquic):** Client receives `HeadersReceived` + `DataReceived`
(the body bytes arrive), but the QUIC stream FIN (`stream_ended = True`) is
never received. Client hangs → times out → sends `ApplicationClose 0x0`.

**Root cause:** `h3 = 0.0.8` writes a GREASE frame on the first request
stream per connection during `finish()`. aioquic mis-handles the GREASE-frames-
before-FIN sequence.

**Fix:** `src/http3.rs:68` — `.send_grease(false)` on the h3 connection
builder. This disables GREASE frames entirely.

**Verified by:** `tests/proxy_http3.rs::http3_stream_finishes_cleanly` — 3
consecutive GET requests over one h3 connection, all complete with clean
stream FINs.

**Canonical test client:** Rust in-process h3 client (`h3` + `h3-quinn` +
`quinn`). No dependency on aioquic for testing.

## H3 test client architecture

The h3 tests use a Rust in-process client:

```rust
fn h3_client_config(ca_pem: &str) -> rustls::ClientConfig {
    // builds config with root = CA PEM, ALPN = [b"h3"]
}

async fn h3_get(proxy_h3_addr, ca_pem, target_host, target_port, path) -> (Status, body) {
    // 1. Create quinn endpoint
    // 2. Connect (QUIC) to proxy_h3_addr with SNI = target_host
    // 3. h3::client::new(connection)
    // 4. Send GET request with absolute-form URI (https://host:port/path)
    // 5. recv_response → recv_data loop → recv_trailers (assert None)
    // 6. Return (status, body string)
}
```

Key: ALPN must be set to `[b"h3"]` on the rustls `ClientConfig` or the
QUIC handshake fails with "peer doesn't support any known protocol".

## CA certificate details

| Property | Root CA | Leaf |
|----------|---------|------|
| Validity | now-1d .. now+20y | now-1d .. now+365d |
| BasicConstraints | CA, Unconstrained | NoCa |
| KeyUsage | KeyCertSign, CRLSign, DigitalSignature | DigitalSignature, KeyEncipherment |
| ExtendedKeyUsage | — | ServerAuth |
| SKI / AKI | SKI present (auto by rcgen) | AKI present, value = CA's SKI |
| Subject | `CN=mitm-proxy Root CA, O=mitm-proxy` | `CN=<host>` |
| SAN | — | DnsName or IpAddress matching host |
| Signing key | Generated once, persisted to `{ca_dir}/mitm_ca.key` | Generated per-request, ephemeral |

The CA keypair is persisted to disk and reused across restarts. Leaves are
cached by SNI in `DynamicCertResolver`'s `HashMap` under a `Mutex`.
